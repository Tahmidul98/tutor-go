# Tutor GO

A free, mobile-friendly app for private tutors: students, class scheduling, monthly billing, receipts, and reminders.

## Develop

    npm install
    cp .env.example .env.local   # fill in Supabase values
    npm run dev

## Test

    npm test     # unit tests (Vitest)
    npm run e2e  # end-to-end (Playwright)
